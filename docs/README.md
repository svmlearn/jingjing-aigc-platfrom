# docs

这个目录是 `小红书抖音矩阵获客平台` 的文档主入口。

当前分层约定如下：

- `handoff/`：交接文档、冻结说明、任务书
- `progress/`：执行日志、验证记录、阶段结论
- `探索/`：方案探索、竞品拆解、外部项目研究、尚未进入正式实现的想法
- `产品文档/`：PRD、信息架构、页面清单、业务规则
- `架构规范/`：接口约束、状态机、发布链路规则、Prompt 规范

外部开源项目代码不放在 `docs/`，统一放在：

- `../references/open-source/`

建议阅读顺序：

1. 先读根目录 `AGENTS.md`
2. 再读 `探索/2026-04-19-小红书抖音矩阵获客平台-初版方案.md`
3. 如需借鉴外部实现，再读 `../references/open-source/README.md`
4. 后续如有 `handoff/`、`progress/`、`产品文档/`，再按任务需要继续读取
