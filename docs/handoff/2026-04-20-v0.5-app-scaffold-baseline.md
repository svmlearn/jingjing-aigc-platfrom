## 7. 下一步分支建议

从当前 scaffold commit 之后开两个分支：

```text
feature/a-core-import
feature/b-admin-ui-rewrite
```

### A 分支

负责：

- Supabase migration 接入
- 邀请码注册
- 商户资料 API
- ApifyProviderAdapter
- ImportJob 状态机
- source_items / imported_comments 落库

### B 分支

负责：

- 注册页 UI
- 商户资料页 UI
- 导入页 UI
- 内容中心 UI
- 内容详情和评论列表
- 改写工作台
- 草稿体验

---

## 8. 注意事项

- B 分支可以先用 mock，但必须走 `src/contracts/**`
- B 分支不能直接调用 Apify / OpenAI
- A 分支不能把 service role 或 Apify token 暴露给客户端
- 新 token 需要写入本地 `app/.env.local`，不要提交
