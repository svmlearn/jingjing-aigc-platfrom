### 3.2 邀请码注册与商户资料 API

新增 API：

```text
POST /api/invitation-codes
POST /api/auth/register-with-invite
GET  /api/merchant-profile
PATCH /api/merchant-profile
```

关键点：

- 邀请码创建通过服务端 `ADMIN_SETUP_SECRET` 保护。
- 注册时服务端使用 Supabase admin 创建 auth user。
- 邀请码兑换与商户创建通过 SQL RPC 完成，避免重复兑换。
- 商户资料读写通过服务端鉴权后访问 service role repository。
- 如果商户已经创建成功但自动 sign-in 失败，不再回滚邀请码和用户，返回 `sessionEstablished: false`，前端可再走登录。
