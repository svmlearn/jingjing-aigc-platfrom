# V2.2 Admin Auth RBAC Handoff

日期：2026-04-27
Branch：`codex/v2.2-admin-auth-rbac`
状态：待验收 / 不 merge main

## 当前目标

完成 V2.2 平台后台账号登录与两级角色权限基础：

- 后台登录从共享 `ADMIN_SETUP_SECRET` 改为邮箱 + 密码。
- Supabase Auth 管理密码。
- `platform_admin_users` 管理后台身份、角色、状态。
- `super_admin` / `admin` 两级 RBAC。
- 系统配置页支持超管维护管理员账号。

## 已完成内容

### 登录

- `platform-admin-login` 已改为邮箱密码登录。
- 首个 `super_admin` 初始化入口已放在登录页：
  - 仅当 `platform_admin_users` 为空时展示。
  - 需要 `ADMIN_SETUP_SECRET`。
  - 创建 Supabase Auth 用户和 `platform_admin_users` 身份记录。
- disabled 管理员登录会被拒绝。

### RBAC

- 新认证工具集中在 `app/src/lib/auth/platform-admin-session.ts`。
- API 权限入口集中在 `app/src/server/api/errors.ts` 的 `assertPlatformAdminAccess()`。
- `super_admin` 专属操作：
  - 系统配置保存。
  - 管理员账号 CRUD 基础能力。
  - 生成 / 启停邀请码。
  - 修改商户状态 / 会员档位。
- `admin` 仍可查看后台、查看设置、维护知识接口。

### 管理员账号

- 新增 API：
  - `app/src/app/api/platform-admin/admin-users/route.ts`
  - `app/src/app/api/platform-admin/admin-users/[adminUserId]/route.ts`
- 新增 repository 能力：
  - `listPlatformAdminUsers`
  - `createPlatformAdminUser`
  - `updatePlatformAdminUser`
- 系统配置页新增管理员账号面板，仅 `super_admin` 可见。
- 保护规则：不能降级或禁用最后一个 active `super_admin`。
