## 验收重点

- 创建出来的新 Agent 默认可为 draft，draft Agent 不能设为线上。
- 空 Prompt 只能保存为草稿，不能发布。
- 发布 Prompt 后旧 active 归档，新版本 active。
- 回滚只能从 archived 版本回到 active。
- 复制 Agent 不复制 `agent_route_bindings` 和 `agent_test_runs`。
- disabled Skill / Knowledge Set 不能通过挂载接口重新成为 enabled 候选。
- Skill / Knowledge Set 被禁用时，已有 enabled 绑定会同步变 disabled。
