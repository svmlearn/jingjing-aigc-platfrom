## 已完成内容

1. 新增代码内置图文 prompt 模块，不引入 CrewAI，不做后台 prompt 配置。
2. `POST /api/content/article-drafts` 已接入现有 OpenAI-compatible LLM runtime。
3. 支持 `create` 和 `rewrite` 两种首次生成模式。
4. 支持 LLM JSON 解析，返回 2 到 3 个小红书图文版本。
5. LLM 无 key、runtime 错误或 parse 错误时使用 fallback 模板，并记录 `llmTrace`。
6. 新增 `POST /api/content/article-drafts/revisions`，支持自然语言修订并追加新版本。
7. 修订版本不覆盖旧版本，新版本会自动成为当前选中版本。
8. `content_drafts.input_snapshot` 记录 `promptMode`、`promptVersion`、`llmTrace`、`riskNotes`、`toneStyle`。
9. 修订 trace 追加到 `input_snapshot.revisionTraces`。
10. 图文工作台左侧展示当前日历卡片。
11. 平台风格与口吻 chip 可选择并传给后端。
12. 右侧新增自然语言修改区域和「按要求修改」按钮。
13. 改写模式无参考素材时，前后端都阻断生成。
14. 默认 LLM runtime 已改为 SiliconFlow，并增加 Supabase 旧存 OpenAI 默认地址时的自动归一兜底。
