## 已完成

### 1. Skill 管理

- 平台管理台支持新建 Skill。
- 支持编辑名称、description、when_to_use、body、status、dependencies。
- 支持启用 / 禁用 Skill。
- 禁用 Skill 后沿用 repository 逻辑，将关联的 enabled bindings 置为 disabled。

### 2. Agent 配置与 System Prompt

- Agent 配置页支持编辑 System Prompt 草稿。
- 支持保存草稿，不影响当前 active prompt。
- 支持发布草稿为 active。
- 支持从 Prompt 历史版本回滚 archived 版本。
- 启用 Agent、设为默认 Agent 前校验 active System Prompt。
- 当前默认 Agent 不允许直接下线，需先切换默认 Agent。

### 3. Agent Knowledge Set 挂载

- Agent 配置页支持勾选 Knowledge Set。
- 保存时调用 `/api/platform-admin/agents/[agentId]/knowledge-sets`。
- 仅 enabled Knowledge Set 可保存为 enabled binding。
- 未挂载知识集时保留风险提示，避免误以为平台知识会参与检索。

### 4. Knowledge Set 与平台知识管理

- 知识管理支持新建 Knowledge Set。
- 支持编辑 Knowledge Set 名称、描述和状态。
- 支持启用 / 禁用 Knowledge Set。
- 禁用 Knowledge Set 后沿用 repository 逻辑，将相关 Agent enabled bindings 置为 disabled。
- 文档列表按 Knowledge Set 筛选。
- 文档卡片展示所属知识集。
- 上传平台知识文档时必须选择至少一个 Knowledge Set。
- 上传接口接收 `knowledgeSetIds`，创建文档后写入 `knowledge_set_documents`。

### 5. Agent 调试台

- `/platform-admin/debug` 已从禁用占位改为真实 Agent 调试台。
- 管理员可选择 Agent、测试商家和输入问题。
- 调试运行复用咨询 runtime。
- 调试运行不写真实 `consultation_sessions` / `consultation_events`。
- 调试运行不扣商家积分。
- 调试结果保存到 `agent_test_runs`。
- 调试台展示最终回复、工具摘要、知识命中和运行时配置快照。

### 6. 会员 / 积分 gate 与用量事件

- 商家端真实咨询调用前执行 `checkConsultationEntitlement`。
- 自动确保 `merchant_credit_accounts` 存在。
- 首次创建账户时按商家 plan 写入初始 grant ledger。
- 积分不足时阻止本次 AI 调用，并返回业务错误。
- 成功咨询后写入 `merchant_usage_events`。
- 成功咨询后写入 `merchant_credit_ledger` 消耗流水。
- Supabase admin 未配置时降级为 skipped usage event，不阻断本地 demo。

### 7. Runtime 约束

- Agent 运行时只把 enabled Knowledge Set 展开为平台 knowledge document scope。
- disabled Knowledge Set 即使 binding 仍存在，也不会进入平台知识检索范围。
- Agent 调试模式可运行 draft_or_active prompt 和非 enabled agent，用于后台配置验证。
- 商家端真实咨询在扣积分和写用户消息前校验本轮是否有可用 Agent 容器；无默认 Agent 但存在 enabled Agent 时提示「请选择一个专家开始咨询」，无任何 enabled Agent 时提示「咨询服务暂未配置，请联系平台管理员」。
