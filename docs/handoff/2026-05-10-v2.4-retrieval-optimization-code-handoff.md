# 2026-05-10 V2.4 检索优化代码落地 Handoff

## 当前目标

把 V2.4 PRD 中新增的检索优化规则落到代码：系统不做一个混合大检索，而是按图文文案、图文配图、视频脚本、AI 剪辑四类消费场景拆成小检索，并保留可解释的检索留痕。

## 已完成内容

1. 新增 `app/src/lib/material-retrieval.ts`
   - 支持 `retrievalTarget` 过滤。
   - 支持 query keyword 召回和重排。
   - 支持中文 query 滑窗分词。
   - 输出 `score`、`queryTerms`、`matchReasons`。
2. `/api/materials` 已支持 `query` 参数。
3. 图文生成已拆分：
   - `copyQuery`：文本知识库 + 爆款内容。
   - `imageQuery`：项目图片素材。
4. 视频脚本生成已把脚本任务 query 传入 `script_context` 检索。
5. 今日任务卡素材提示已按当天主题 query 重排。
6. AI 剪辑 worker payload 新增：
   - `materialContext.sceneAssetQueries`
   - `materialContext.assetMatchPlan`
   - 更可操作的 `missingVideoAssetHints`
7. 已补执行记录：
   - `docs/progress/2026-05-10-v2.4-retrieval-optimization-code.md`
