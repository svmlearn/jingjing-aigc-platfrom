# 2026-05-11 V2.3.1 中介成员端任务执行与自动成片实现任务书

状态：`已实现，待验收 / 待合并`
分支：`codex/v2.3.1-member-app`
来源 PRD：`docs/产品文档/V2.3.1-中介成员端任务执行与自动成片PRD.md`

## 目标

按 V2.3.1 PRD 在现有项目上实现成员端任务执行闭环，不新起项目。

核心交付：

1. 管理员后台不再把 `今日任务` 作为正式主入口；今日任务迁移到成员端。
2. 成员端有独立入口，首版按 H5/PWA 验证。
3. 成员端支持邀请码 / 邀请链接加入 team。
4. 成员登录后默认进入纯文字项目介绍首页，不提供 chatbot。
5. 成员端一级结构为 `项目介绍`、`内容日历`、`我的内容`。
6. 内容日历展示今日任务和本周预览。
7. 图文任务详情直接展示已生成图文内容包和图片，不要求成员点击生成。
8. 视频任务详情直接展示已生成故事大纲 / 镜头脚本，支持手机素材上传、AI 剪辑、状态查看、预览和下载。
9. 成员内容和任务严格按当前成员隔离。
10. 补齐必要实现记录和验证记录。

## 范围

### P0 必做

- 成员入口页面 / 路由。
- 成员邀请码加入 team 的最小可用链路。
- 成员项目介绍首页。
- 成员内容日历 / 今日任务首页。
- 成员图文任务详情页。
- 成员视频任务详情页。
- 成员我的内容入口。
- 后台导航或入口文案调整，避免管理员正式主导航继续暴露 `今日任务`。
- 服务端 API 或现有 API 复用，保证成员端不依赖 Web dashboard 临时状态。
- 本地 demo / 无真实 Supabase 环境下仍可完成可验收流程。

### P0 不做

- 小程序原生包。
- iOS / 安卓原生 App。
- 真实平台发布。
- 账号授权。
- 声纹克隆、片头片尾模板库、批量套片。
- 复杂素材不足自动判断。
- 复杂多团队组织架构。

## 实现结果

已按 P0 完成：

1. 成员端独立 H5 路由：`/member`、`/member/calendar`、`/member/article/[taskId]`、`/member/video/[taskId]`、`/member/history`、`/member/invite`。
2. 成员端默认首页是纯文字项目介绍，不提供 chatbot。
3. 内容日历展示今日图文和视频任务，以及未来 7 天预览。
4. 图文任务详情直接展示 `generatedArticle`，提供复制文案和图片 / 图片 brief。
5. 视频任务详情直接展示 `generatedVideoScript`，提供素材上传和 AI 剪辑状态链路。
6. 成员邀请码加入 team API 和 Supabase migration 已补。
7. 后台正式导航移除 `今日任务`，保留 `成员端预览`。
8. 根入口页新增 `成员端` 入口。
