## 2. 当前核心判断

香港方案不是技术上的执念，只是因为 `ba-ba-ke.com` 可能挂在老板香港公司名下，且未确认能否转到国内公司主体。如果域名主体无法转到国内公司，香港部署可以绕开大陆 ICP 备案，先快速试运营。

如果可以重新买一个域名，并用国内正规公司完成域名实名和 ICP 备案，则没有必要执着香港。目标用户主要是国内房产中介时，大陆服务器 + 大陆对象存储 + 大陆数据库才是长期更稳的方案。

当前判断：

| 条件 | 推荐路线 |
| --- | --- |
| 有国内公司主体，可新买域名或可把 `ba-ba-ke.com` 转到国内公司实名 | 走大陆服务器，大陆备案，大陆 COS/OSS，大陆 PostgreSQL |
| `ba-ba-ke.com` 已绑定香港公司且不能转国内公司，又想尽快试运营 | 走香港服务器，香港 COS/OSS，香港 PostgreSQL，HTTPS |
| 只是 phase1 技术验证，不急正式上线 | 先用 IP 跑通链路，暂不被备案卡住 |
| 后续要给国内中介规模化长期使用 | 尽量回到大陆备案路线 |

明天待确认：

1. `ba-ba-ke.com` 当前域名持有人 / 实名主体是谁。
2. 该域名是否已经挂在香港公司名下。
3. 该域名是否可以转到国内公司主体。
4. 如果不能转，是否接受新买一个域名给国内公司备案。
5. 国内公司是否可以作为 ICP 备案主体，并承担后续云账号、域名、服务器实名一致性。

确认后再决策：

```text

再决策：腾讯云 vs 阿里云
最后再买：服务器 + 对象存储 + PostgreSQL
```

当前建议：

1. 如果国内对象存储和后续数据库都准备走腾讯云，优先买腾讯云 CVM。理由是 CVM、COS、后续 PostgreSQL 更容易放在同一家云、同区域或近区域，权限、内网、工单和排障都更简单。
2. 如果只看这台 8 核 16G 服务器的 1 个月验证成本，阿里云当前更便宜，便宜约 `¥186.36`。
3. 不建议服务器买阿里云、对象存储买腾讯云、数据库再买第三家。短期能跑，但排障会被跨云链路、跨云流量和权限配置拖慢。
4. 这次只是 phase1 IP 验证，不做 ICP 备案；如果后面要用 `ba-ba-ke.com` 正式备案，服务器购买时长需要按云厂商备案要求改成 3 个月及以上。

结论：

- 更省心：腾讯云 CVM + 腾讯 COS + 腾讯云数据库 PostgreSQL。
- 更省钱：阿里云 ECS + 阿里云 OSS + 阿里云 RDS PostgreSQL。
- 不管选哪家，本阶段都先买 1 台 8 核 16G、100 GiB 系统盘、5 Mbps 按流量公网的单机验证服务器即可。

### 8.3 香港方案的边界

香港服务器不用大陆 ICP 备案的前提是：

```text
域名解析到香港服务器
对象存储在香港
数据库在香港
不使用中国大陆服务器作为 Web 接入
不使用中国大陆 CDN 节点加速
不把对象存储自定义域名接到大陆需要备案的资源上
```

香港方案可以配 HTTPS，也可以做 PWA。PWA 需要的是 HTTPS 安全上下文，不是必须 ICP。

但香港方案不能顺手解决大陆 CDN 加速问题。如果要使用中国大陆 CDN 节点给国内用户加速，通常仍然需要域名完成 ICP 备案。也就是说，香港方案的优势是快和免大陆备案，不是国内访问质量最优。

对国内用户的实际影响：

| 链路 | 香港方案可用性 |
| --- | --- |
| 手机打开 PWA 页面 | 通常可用 |
| 登录 / API 请求 | 通常可用 |
| 上传视频素材 | 可用，但跨境链路可能慢或波动 |
| 下载生成视频 | 可用，但跨境链路可能慢或波动 |
| 国内 CDN 加速 | 不应作为免备案方案的一部分 |

### 8.4 香港 vs 大陆的取舍

| 方案 | 优点 | 风险 / 代价 |
| --- | --- | --- |
| 香港服务器 + 香港对象存储 + 香港数据库 | 不等大陆 ICP，最快可试运营；适合 `ba-ba-ke.com` 无法转国内主体时使用 | 国内用户跨境访问，视频上传下载稳定性不如大陆；不能直接解决大陆 CDN 加速 |
| 大陆服务器 + 大陆对象存储 + 大陆数据库 | 国内用户体验更稳，适合长期给中介规模化使用 | 需要国内公司主体、域名实名、ICP 备案、服务器购买时长满足备案要求 |

当前建议：

1. 如果明天确认可以用国内公司备案，优先走大陆路线。
2. 如果 `ba-ba-ke.com` 已经固定在香港公司且不能转国内，又不想换域名，则优先走香港路线做快速试运营。
3. 如果愿意新买域名给国内公司备案，就不要被 `ba-ba-ke.com` 卡住。
4. 无论大陆还是香港，都尽量同一家云闭环：服务器、对象存储、PostgreSQL 不要跨云混搭。
