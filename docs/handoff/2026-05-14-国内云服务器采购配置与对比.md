# 2026-05-14 国内云服务器采购配置与对比

状态时间：`2026-05-14 21:05:45 CST`

## 1. 文档目的

记录国内 phase1 验证服务器采购参数，避免购买页关闭后丢失配置。

本轮目标不是正式生产上线，而是先购买 1 台国内服务器，用于验证：

```text
国内 IP 访问页面
-> 国内 PostgreSQL
-> 国内 COS
-> app / API / worker 单机混跑
-> 手机浏览器上传素材
-> worker 生成 final.mp4
-> 国内 COS 重新签名下载
```

- 100 GiB 系统盘足够放代码、Docker、日志和 worker 临时目录；大素材和成片仍应放 COS。
- 第一阶段只做 IP 验证，不直接用于备案，所以先买 1 个月可以控制成本。

### 2.2 网络与公网

| 项 | 选择 |
| --- | --- |
| VPC | Default-VPC（默认） |
| 子网 | Default-Subnet（默认） |
| 公网 IP | 购买 |
| 线路类型 | BGP |
| 带宽计费模式 | 按流量计费 |
| 带宽上限 | 5 Mbps |
| IPv6 | 不开 |

选择理由：

- 必须购买公网 IP，否则不能用手机和浏览器直接访问国内 IP。
- 服务器主要跑 Web/API/worker 调度，素材和成片应通过浏览器直传 COS / 从 COS 下载，不应让服务器长期承担大视频流量。
- 按流量计费 + 5 Mbps 更适合短期验证；比 1 Mbps 更顺畅，比固定大带宽更省钱。

## 6. 腾讯云 vs 阿里云取舍

| 维度 | 腾讯云 CVM | 阿里云 ECS |
| --- | --- | --- |
| 当前地域 | 上海 | 杭州 |
| 规格 | `C6.2XLARGE16` | `ecs.c9i.2xlarge` |
| CPU / 内存 | 8 核 / 16 GiB | 8 vCPU / 16 GiB |
| 镜像 | Ubuntu Server 22.04 LTS 64 位 | Ubuntu 22.04 64 位（安全加固） |
| 系统盘 | 增强型 SSD 100 GiB | ESSD PL0 100 GiB |
| 公网 | 按流量计费，5 Mbps | 按使用流量，5 Mbps |
| 安全组 | 22 / 80 / 443 / ICMP | 22 / 80 / 443 / ICMP |
| 登录 | 自动生成密码 | 创建后设置 |
| 自动续费 | 不勾选 | 不勾选 |
| 1 个月配置费 | `¥980.00` | `¥793.64` |
| 流量费 | `¥0.80/GB` | 页面显示为后付费项，按实际使用计费 |

当前建议：

1. 如果国内对象存储和后续数据库都准备走腾讯云，优先买腾讯云 CVM。理由是 CVM、COS、后续 PostgreSQL 更容易放在同一家云、同区域或近区域，权限、内网、工单和排障都更简单。
2. 如果只看这台 8 核 16G 服务器的 1 个月验证成本，阿里云当前更便宜，便宜约 `¥186.36`。
3. 不建议服务器买阿里云、对象存储买腾讯云、数据库再买第三家。短期能跑，但排障会被跨云链路、跨云流量和权限配置拖慢。
4. 这次只是 phase1 IP 验证，不做 ICP 备案；如果后面要用 `ba-ba-ke.com` 正式备案，服务器购买时长需要按云厂商备案要求改成 3 个月及以上。

结论：

- 更省心：腾讯云 CVM + 腾讯 COS + 腾讯云数据库 PostgreSQL。
- 更省钱：阿里云 ECS + 阿里云 OSS + 阿里云 RDS PostgreSQL。
- 不管选哪家，本阶段都先买 1 台 8 核 16G、100 GiB 系统盘、5 Mbps 按流量公网的单机验证服务器即可。
