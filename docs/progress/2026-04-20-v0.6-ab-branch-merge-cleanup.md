本项目当前仍处于 0 到 1 的 MVP 推进阶段，A/B 分支是一次性任务隔离空间，不是长期维护分支。

清理的目的：

1. 避免未来 Agent 误进入旧 worktree 继续开发。
2. 避免旧分支落后于 `main` 后产生额外同步成本。
3. 让 `main` 继续作为已验收事实源。
4. 下一轮任务从最新 `main` 重新拆新的短期分支。

删除分支名不会丢失历史。本轮 A/B 的提交已经通过 merge commit 进入 `main`，对应 handoff 也已经保留在 `docs/handoff/` 中。
