## Vercel 部署问题与修正

首次部署构建成功，但访问结果为 `NOT_FOUND`。

定位结果：

- 新建 Vercel 项目的 `Framework Preset` 默认落在 `Other`
- 该设置会让项目按通用静态构建处理，导致 Next.js 路由产物无法正常对外提供

修正方式：

- 新增文件：`app/vercel.json`
- 内容为：

```json
{
  "$schema": "https://openapi.vercel.sh/vercel.json",
  "framework": "nextjs"
}
```

修正后重新部署，Vercel 构建日志已明确识别：

- `Detected Next.js version: 16.2.4`
