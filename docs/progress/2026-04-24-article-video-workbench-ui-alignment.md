# 2026-04-24 图文 / 视频工作台 UI 与流程对齐记录

## 背景

用户在 staging 验收时指出：

- 图文工作台「创作 / 改写」切换语义不够清晰，创作模式不应该出现参考素材。
- 图文工作台左侧配置区在小窗口下无法向下滚动，底部缺少明确的「开始创作 / 开始改写」入口。
- 视频工作台不应只是表单，更应接近 AI 原型图中的「AI 对话 + 脚本画布」协同模式。
- 视频页「生成脚本 / 创建视频任务」按钮语义有歧义，应改成更贴近流程的生成态与剪辑态。

## 本轮完成

### 图文工作台

- 顶部模式切换改为：
  - `从 0 到 1创作`
  - `基于素材改写`
- 仅在 `基于素材改写` 模式展示参考素材区域。
- 从素材中心跳转携带 `materialId / materialReferenceId` 时，自动进入改写模式并加载该参考素材。
- 左侧配置区改为可滚动。
- 左侧底部新增固定 CTA：
  - 创作模式：`开始创作`
  - 改写模式：`开始改写`
- 生成草稿时，改写模式会把参考素材标题、拆解说明、引用 id 合并进 `extraRequirement`，继续复用现有 `article-drafts` API。

### 视频工作台

- 页面结构改为：
  - 左侧：AI 对话区，可输入脚本意见。
  - 右侧：脚本画布，可收起 / 展开 / 放大。
- 顶部按钮改为：
  - `生成视频脚本`
  - `AI 一键剪辑`
- 视频脚本生成仍复用现有 `/api/content/video-scripts`。
- AI 一键剪辑仍复用现有 `/api/video-edit-jobs`。
- 从咨询内容日历跳转时，会把 `strategyTag` 作为 query 参数带入图文 / 视频工作台。
- 从素材中心跳转到视频工作台时，会加载参考素材并作为脚本上下文。
- 脚本生成后在画布中展示镜头分段、台词/音效、素材上传占位与任务状态提示。

## 验证

- `npm run lint`：通过。
- `npm run build`：通过。

## 后续仍需接后端的部分

- 视频画布中的「传镜头」目前只更新当前页面状态，尚未接真实媒体上传与分段素材绑定。
- 视频脚本画布目前根据生成脚本文本切段，后续应让后端输出结构化镜头表。
- 图文改写已把参考素材上下文传入生成请求，但后续可以扩展为正式的 `materialReferenceId` 字段，而不是拼入 `extraRequirement`。
