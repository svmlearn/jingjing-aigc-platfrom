# V2.2 Admin Auth RBAC Progress

日期：2026-04-27
Branch：`codex/v2.2-admin-auth-rbac`
基线：`main` at `77a4429 Merge V2.2 admin foundation`

## 本轮目标

把平台后台从 `ADMIN_SETUP_SECRET` 共享口令登录，改为：

- Supabase Auth 邮箱 + 密码登录。
- `platform_admin_users` 作为后台身份、角色和状态表。
- `super_admin` / `admin` 两级 RBAC。
- 首个 `super_admin` 一次性初始化入口。
- 系统配置页预留并实现管理员账号管理入口。

## 已完成

### 登录与初始化

- `platform-admin-login` 改为邮箱密码登录。
- 当 `platform_admin_users` 为空时，登录页切换为首个 `super_admin` 初始化表单。
- 初始化仍要求 `ADMIN_SETUP_SECRET`，但只用于首个超管创建，不再作为日常后台登录口令。
- 登录成功后通过 Supabase Auth session 保持后台会话。
- `disabled` 管理员登录时会立即 sign out 并返回登录页错误。

### 权限基础

- 新增 `getCurrentPlatformAdmin()` / `authenticatePlatformAdminWithPassword()` 等后台认证工具。
- API guard 改为异步 `assertPlatformAdminAccess(request, { roles })`。
- 普通 `admin` 可访问查看类接口和知识维护接口。
- `super_admin` 限定能力：
  - 修改系统配置。
  - 管理管理员账号。
  - 生成 / 启停邀请码。
  - 修改商户状态 / 会员档位。

### 管理员账号管理

- 新增 API：
  - `GET /api/platform-admin/admin-users`
  - `POST /api/platform-admin/admin-users`
  - `PATCH /api/platform-admin/admin-users/[adminUserId]`
- 管理员密码由 Supabase Auth 管理。
- `platform_admin_users` 记录邮箱、显示名、角色、状态、创建人和最近登录时间。
- 禁止把最后一个 active `super_admin` 降级或禁用。
- 系统配置页新增 `super_admin` 可见的管理员账号管理面板。
- `admin` 查看系统配置时为只读，无法保存配置或管理管理员。

### 页面基础

- 平台后台 layout 会读取当前后台管理员，并在左侧 shell 展示当前账号和角色。
- 邀请码页面对 `admin` 隐藏生成按钮，并禁用启停操作入口。
- 邀请码生成页对非 `super_admin` 显示无权限提示。
