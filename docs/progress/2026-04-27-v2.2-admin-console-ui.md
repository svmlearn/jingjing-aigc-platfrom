## 本轮目标

完整还原 `docs/designs/AIGC平台后台` 的暗色平台后台体验，并将 V2.2 foundation contracts 用于 Agent 配置、技能管理、知识集预览和调试台布局。

## 已完成

1. 重构 `PlatformAdminShell` 为暗色控制台。
2. 导航分组调整为：
   - 运营管理：总览、邀请码管理、商户管理、知识管理
   - Agent 能力：Agent 配置、技能管理、Agent 调试
   - 系统：系统配置
3. 新增后台暗色 UI helper：页面标题、Panel、状态 Badge、空态、通知、表单控件 class。
4. 改造已有页面：
   - `/platform-admin`
   - `/platform-admin/invitation-codes`
   - `/platform-admin/invitation-codes/new`
   - `/platform-admin/merchants`

   - `/platform-admin/settings`
5. 新增 V2.2 Agent 能力页面：
   - `/platform-admin/agents`
   - `/platform-admin/skills`
   - `/platform-admin/debug`
6. 接入 foundation repository / contracts：
   - `getAgentConsoleFoundationState`
   - `listAgentPromptVersions`
   - `listAgentSkillBindings`
   - `listAgentKnowledgeSetBindings`
7. 对暂未实现写 API 的地方使用明确禁用态：
   - Agent 复制 / 设置线上 / 保存
   - Skill 新建 / 启用 / 禁用 / 保存
   - Debug 运行测试
   - 商户状态 / 会员变更
   - Knowledge Set 新建与上传时强制选择知识集
8. 保留真实 API 边界：
   - 邀请码列表 / 创建 / 启停继续走现有 API
   - 知识文档列表 / 上传 / 重试 / 删除继续走现有 API
   - 系统配置继续走现有 `/api/platform-admin/settings`
