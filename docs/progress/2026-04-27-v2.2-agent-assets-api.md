### Repository 写操作

- Agent：列表、详情、创建、编辑、复制。
- Prompt：草稿保存、发布、历史读取、归档版本回滚。
- Skill：创建、详情、编辑、启用、禁用。
- Knowledge Set：创建、详情、编辑、启用、禁用。
- Knowledge 文档：加入知识集、从文档视角替换所属知识集。
- Agent 资产挂载：替换 Skill / Knowledge Set enabled 绑定。
- 线上绑定：切换 `consultation_default`。
- 审计日志：写入 `platform_admin_events`。

### 验收规则落点

- draft / disabled Agent 不能设为线上，只有 `enabled` Agent 可以切到 `consultation_default`。
- 空 Prompt 可以保存为草稿，但不能发布或回滚为 active。
- 发布 Prompt 时旧 active 会归档，新 draft 会变成 active。
- 回滚 Prompt 只允许 archived 版本回滚为 active。
- 复制 Agent 不复制线上绑定和测试记录；会生成 draft Agent，并复制 prompt / Skill 绑定 / Knowledge Set 绑定。
- disabled Skill 不能作为新的 enabled 候选挂到 Agent；Skill 禁用时会同步禁用已有 enabled 绑定。
- disabled Knowledge Set 不能作为新的 enabled 候选挂到 Agent；Knowledge Set 禁用时会同步禁用已有 enabled 绑定。
