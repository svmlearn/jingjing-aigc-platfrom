### 2. 关键约束

- Agent 生命周期：`draft | enabled | disabled`
- Prompt 版本状态：`draft | active | archived`
- 每个 Agent 最多一个 `active` prompt
- 每个 Agent 最多一个 `draft` prompt
- Skill / Knowledge Set 状态：`draft | enabled | disabled`
- 绑定状态：`enabled | disabled`
- `agent_route_bindings.route_key` 第一版限制为 `consultation_default`
- `consultation_default` 保持唯一
- 关键 JSON 字段增加 `jsonb_typeof` 检查
- 所有主要后台配置表启用 RLS，后续通过 server/service role 访问

### 3. 初始化 seed

migration 内置 seed：

1. 创建 `base_platform_knowledge` 基础平台知识集。
2. 将已有 `scope = platform` 的 `knowledge_documents` 加入基础平台知识集。
3. 在没有有效 `consultation_default` 绑定时，创建 `initial_consultation_agent`。
4. 将旧 `platform_settings.consultation_agent.systemPrompt` 迁移为初始 Agent 的 active prompt。
5. 将初始 Agent 绑定基础平台知识集。
6. 创建 `consultation_default -> initial_consultation_agent` route binding。
