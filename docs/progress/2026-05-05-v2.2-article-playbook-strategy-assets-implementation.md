# 2026-05-05 V2.2 图文策略层与策略资产 Markdown 实现记录

## 目标

落实 `docs/产品文档/V2.2-图文工作台小红书爆款策略层小PRD.md` 中已确认的主线：

- 策略资产可以像 Markdown 文档一样自由生长，不再被固定字段卡死。
- 图文 / 视频工作台可以稳定读取策略资产文档作为业务上下文。
- 图文工作台支持 `articlePlaybook` 创作策略。
- 风控、写作说明、封面花字、配图结构建议能在图文结果中展示。

## 已完成

1. 新增 Supabase migration：`202605050001_strategy_asset_markdown.sql`。
   - `merchant_strategy_assets.strategy_markdown`
   - `merchant_strategy_assets.canonical_snapshot`
   - `merchant_strategy_assets.compiled_context`

2. 扩展策略资产数据层。
   - 新增 `MerchantStrategyAssetDto`。
   - 新增 `getMerchantStrategyAssetDocument`、`ensureMerchantStrategyAssetDocument`、`upsertMerchantStrategyAssetDocument`。
   - 保留旧 `strategy_snapshot` 兼容，`strategy_markdown` 为主文档。

3. 咨询页右侧从固定字段卡片改成 Markdown 策略资产文档视图。
   - 支持按 Markdown 标题和列表渲染。
   - 空文档时使用当前 `strategySnapshot` 生成 fallback Markdown。

4. 策略资产 Editor 改为同时维护固定摘要字段和 `strategyMarkdown`。
   - 工具 schema 要求完整 `strategyAsset` 包含 `strategyMarkdown`。
   - `strategyMarkdown` 允许 Markdown 章节自由扩展。
   - 固定字段仍做 guardrail，避免聊天口语和结构化噪音写入摘要字段。

5. 图文工作台新增创作策略。
   - `balanced_seed`
   - `viral_generation`
   - `traffic_rewrite`
   - `compliance_safe`
   - `ip_persona`

6. 图文生成链路接入策略资产 Markdown。
   - 请求 schema 支持 `articlePlaybook`。
   - Prompt context 包含 `strategyAssetMarkdown` 和 `articlePlaybook`。
   - `inputSnapshot` 记录策略值、策略文档、封面花字、配图结构、写作说明和风控提示。

7. 视频生成链路接入策略资产 Markdown。
   - `VideoGrowthContext`、`ScriptProductionBrief`、视频工作台 Agent context pack 都携带策略文档。
   - Prompt 规则明确策略文档是业务资料，不是系统指令。
