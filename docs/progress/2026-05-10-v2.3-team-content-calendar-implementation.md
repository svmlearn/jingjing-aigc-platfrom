## 背景

本轮变更来自房地产试点客户需求的进一步澄清：咨询台仍保留，但主要作为 team 管理员 / 核心销售的团队选题入口；普通销售或中介成员最终更适合通过小程序、H5 或轻客户端领取今日 / 本周任务，生成图文、查看视频脚本、上传素材并一键剪辑。

因此，本轮没有新起项目，而是在现有商家端、咨询台、知识库、素材中心、图文工作台、视频工作台和 worker 链路上补齐 `daily_task` 来源。

## 已完成

- 新增 `merchant_team_members`，把当前 `merchant_profiles.id` 作为 V1 team 载体，owner 自动成为 team 管理员。
- 新增 `daily_content_tasks`，按 `merchant_id + user_id + task_date` 固化成员今日任务，保证刷新后不随机变化。
- 新增内容归属字段，`content_drafts.created_by_user_id` 和 `video_edit_jobs.created_by_user_id` 用于成员级“我的内容”隔离。
- 新增 `/api/daily-content-tasks`，返回今日任务、未来 7 天任务和当前用户 team role。
- 今日任务生成会读取 merchant 策略资产、内容日历草案和素材库；同一 team 主题下，按用户和日期稳定分配不同表达角度。
- 图文生成支持 `source = daily_task` 和 `dailyTaskId`，不再强依赖咨询 `sessionId`。
- 视频脚本 Agent 支持 `source = daily_task` 和 `dailyTaskId`，无咨询 session 时用今日任务 + 共享策略资产组装虚拟策略上下文。
- Web `/dashboard` 改为今日任务预览；旧咨询台迁移到 `/dashboard/consultation`，作为团队选题入口。
- 新增 `/member` H5 轻客户端预览入口，用于验证普通成员只看今日 / 本周任务和生成入口的产品形态。
- `ArticleWorkbench`、`VideoWorkbench` 保留，并能从今日任务入口接入。
- 视频工作台仍复用脚本确认、素材上传、创建 `video_edit_jobs`、worker 剪辑和结果回写链路。
- `我的内容`、内容详情、视频任务详情、重试、取消、素材上传 owner 校验都按当前 `userId` 过滤，避免同一 team 成员互相看到或操作对方内容。
- 本地 demo 成功视频任务会返回占位预览资产，真实成片仍由 Supabase + COS + worker 链路负责。

本地 demo 服务验证：

- 服务地址：`http://127.0.0.1:3010`
- `GET /api/daily-content-tasks` 返回今日任务和未来 7 天任务。
- 连续请求 `/api/daily-content-tasks`，同一天同用户的 `today.id` 保持一致。
- 使用 header `x-jingjing-demo-user-id: demo-member-local` 模拟普通成员，`GET /api/daily-content-tasks` 返回 `role = member`，且与 owner 属于同一 demo merchant。
- `/dashboard` 返回 200。
- `/dashboard/article?source=daily_task&dailyTaskId=...` 返回 200。
- `/dashboard/video?source=daily_task&dailyTaskId=...` 返回 200。
- `POST /api/content/article-drafts` 只带 `source=daily_task + dailyTaskId` 可生成图文草稿。
- `POST /api/content/video-workbench-agent` 只带 `source=daily_task + dailyTaskId` 可生成视频脚本草稿。
- 成员 daily task 视频链路继续完成：
  - `POST /api/content/variants/:variantId/approve` 确认脚本，返回 `reviewStatus = approved`。
  - `POST /api/media/complete` 为 daily task 脚本草稿补一条 content draft 视频素材记录。
  - `POST /api/video-edit-jobs` 创建剪辑任务，`inputPayload.render_mode = asset_driven`，`input_assets.length = 1`。
  - `GET /api/video-edit-jobs/:jobId` 在本地 demo worker 时间线后返回 `status = succeeded`、`progressPct = 100`、`currentStage = local_demo_completed`。
- `GET /api/video-edit-jobs?limit=5` 能看到该任务。
- 团队管理员在 `/api/consultation/sessions/:sessionId/messages` 输入“本周小户型回归”选题后，本地 demo 同步生成 `calendarCount = 2` 的 team 内容日历；普通成员随后获取 `2026-05-19` daily task，`teamCalendarSource.calendarItemIds = ["team-calendar-article-1", "team-calendar-video-1"]`，主题为“小户型回归”。
- daily task 图文生成结果包含标题、正文、标签、CTA、封面字建议、配图结构建议；本地 demo 无真实项目图片时，结果通过 `imageStructureSuggestions` 降级提示，不伪造 AI 生图。
- `GET /api/history/records?limit=20` 能看到 daily task 生成的图文草稿、视频脚本草稿和视频剪辑任务。
- 双成员隔离 smoke：
