# 2026-05-11 V2.3.1 成员端实现记录

## 目标

按 `docs/产品文档/V2.3.1-中介成员端任务执行与自动成片PRD.md` 落地 P0 成员端闭环：成员通过邀请码进入独立手机端，先看项目介绍，再进入内容日历，查看已生成图文和视频镜头脚本，上传素材后触发 AI 剪辑，并在我的内容中查看沉淀结果。

## 已完成

1. 成员端 H5 路由已独立：
   - `/member`：项目介绍首页，纯文字项目说明，不放 chatbot。
   - `/member/calendar`：内容日历 / 今日任务。
   - `/member/article/[taskId]`：已生成图文内容包、复制文案、图片 / 图片 brief。
   - `/member/video/[taskId]`：已生成视频镜头脚本、手机素材上传、AI 剪辑状态链路。
   - `/member/history`：我的内容入口。
   - `/member/invite`：邀请码加入入口。
2. 成员端 API 已补齐最小版本：
   - `POST /api/member/invitations/accept`
   - `GET /api/member/tasks/today`
   - `GET /api/member/tasks/week`
   - `GET /api/member/tasks/[taskId]`
   - `GET /api/member/history`
3. `daily_content_tasks` 数据契约扩展：
   - `project`：成员项目介绍所需字段。
   - `articleTask.generatedArticle`：标题、正文、标签、CTA、封面字、匹配图片 / 图片 brief。
   - `videoTask.generatedVideoScript`：故事大纲、镜头脚本、素材上传槽位、预计时长、AI 剪辑 CTA。
4. 邀请码 / 邀请链接加入 team：
   - 新增 `merchant_team_invitation_codes` migration。
   - 新增 `acceptMemberInvitationCode`，真实 Supabase 环境按邀请码绑定 `merchant_team_members`。
   - 本地 demo 环境可用同一 API 完成等价加入流程。
5. 管理员后台边界调整：
   - 后台正式导航不再显示 `今日任务`。
   - `/dashboard` 默认进入 `/dashboard/consultation`。
   - 后台仅保留 `成员端预览` 入口，明确不是后台主任务入口。
6. 登录入口调整：
   - 根入口页新增 `成员端`，指向邀请码入口。

## 验证

- `cd app && pnpm exec tsc --noEmit --pretty false`：通过。
- `cd app && pnpm lint`：通过。
- `cd app && node --test src/server/api/member-content-builders.test.ts`：通过，覆盖项目介绍、图文内容包、视频镜头脚本构建。
- `cd app && node --test src/lib/member-video-workflow.test.ts`：通过，覆盖视频素材已选、AI 剪辑队列 / 剪辑中状态、成片成功后的预览 / 下载 URL 判定。
- `cd app && pnpm build`：通过，Next build 路由表包含成员端页面和成员端 API。
- 本地 demo HTTP 冒烟：
  - `NEXT_PUBLIC_SUPABASE_URL= NEXT_PUBLIC_SUPABASE_ANON_KEY= SUPABASE_SERVICE_ROLE_KEY= pnpm dev --port 3010`：启动成功。
  - `GET /member`、`GET /member/calendar`、`GET /member/invite?code=DEMO-MEMBER`：均返回 `200`。
  - `GET /api/member/tasks/week`：返回项目介绍、内容日历、图文 `generatedArticle`、视频 `generatedVideoScript`。
  - `GET /member/article/<taskId>`、`GET /member/video/<taskId>`：均返回 `200`。
  - `POST /api/member/invitations/accept` 使用 `DEMO-MEMBER`：本地 demo 返回 workspace。

浏览器自动化工具在当前环境未提供可用 Playwright/browser runtime 包，本轮用 Next build + 本地 HTTP 冒烟覆盖路由和 API 可用性。

视频上传到 AI 剪辑的端到端真实出片依赖 COS 上传凭证、LLM 脚本草稿和 video-worker 运行环境；本轮 P0 额外用 `member-video-workflow.test.ts` 固化成员端前端状态契约，确保“已选素材 -> 可发起 AI 剪辑 -> 队列 / 剪辑中 -> 成片成功 -> 预览 / 下载 URL”这条链路有客观测试证据。

## 说明

视频任务的 P0 体验按 PRD 保持为“脚本已生成 -> 成员上传素材 -> 点击 AI 剪辑 -> 队列状态 -> 成片预览 / 下载”。复杂素材不足判断、自动降级、片头片尾模板库、声纹克隆和真实平台发布仍不进入本轮实现。
