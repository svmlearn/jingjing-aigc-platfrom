## 口吻修正

第一次生成的《落实算法安全主体责任基本情况》中出现了不符合正式材料的表述，例如：

```text
提交备案前，建议同步准备并上传或留存以下附件：
```

本轮已按用户要求改为公司正式口吻：

```text
本公司围绕本服务的算法安全管理、内容安全、数据安全、个人信息保护和用户权益保护，形成以下附件材料。相关材料随备案系统要求提交，或作为公司算法安全管理制度文件留存备查。
```

已做口吻扫描，当前生成的星阅科技材料中未再命中以下明显 AI/建议式表述：

```text

```

注意：

- 文件名中带“草案”“待补”的是为了避免后续误认为已经盖章或已经提交。
- 文档正文尽量采用“本公司已/本公司设置/本公司制定/本公司建立”等正式主体口吻。

## 算法安全责任人口径

已向用户说明：

- 不建议填写尚未入职、后续不确定是否继续参与项目的人员。
- 算法安全责任人应由公司内部稳定人员担任。
- 最合适人选是公司技术负责人、研发负责人、信息安全负责人或公司指定的产品技术负责人。
- 该人员不需要亲自开发全部算法，但必须了解产品基本业务、用户素材类型、生成内容类型和主要风险，能接收电话/短信/邮件，并能协调产品、技术、运营、客服和法务处理补材料、投诉、整改和安全事件。

## 后续建议

后续继续推进时，先做以下人工确认：

```text
1. 公司指定算法安全责任人，并确认其姓名、手机号、邮箱、身份证号、部门、职务、工作年限。
2. 公司确认是否愿意给该责任人开具工作证明并盖章。
3. 从营业执照或国家企业信用信息公示系统复制完整经营范围，填入算法备案承诺书。
4. 确认声音克隆 / 音色复用是否纳入本次备案，还是等该功能正式上线前做变更备案。
5. 确认本服务正式开放范围：企业内测、邀请制商家试用，还是面向公众开放注册。
6. 补齐第三方模型/服务商真实清单。
7. 正式上线页面完成后，再补截图附件。
8. 所有材料提交前由公司负责人、法务或合规顾问复核。
```

## 边界

本轮没有提交备案系统，没有替用户确认协议，没有上传真实身份证或工作证明，没有伪造责任人信息，没有填写未经确认的手机号、邮箱、身份证号码。
