下一批要点

按当前状态，最短路径是先把 staging 持久化和图片素材跑通，再接 worker 定时消费。

1. Staging 持久化

  • 执行 batch/job migration。
  • 配置 Dify 与 COS 环境变量。
  • 用真实 Supabase 验证 batch -> job -> draft -> member task。

2. 图片素材闭环

  • 上传项目图片素材。
  • 确认 retrievalTargets 包含 article_image_asset。
  • 验证 Dify 返回 cosPath 后成员端能渲染图片。

3. Worker 常驻消费

  • 配置 CONTENT_GENERATION_WORKER_SECRET。
  • 增加定时或队列消费 run-next。
  • 补重试、超时、失败可视化。

4. 成片与发布

  • 用真实成员上传素材跑 AI 剪辑。
  • 确认成片 COS 回写与预览。
  • 发布前先确认商家、门店、平台、账号和环境。
