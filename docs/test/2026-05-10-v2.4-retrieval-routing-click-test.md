## 1. 测试目标

验证 V2.4 的“按用途分层检索”已经在商家端可用链路中体现：

1. 素材中心能区分爆款参考、项目图片素材、项目视频素材。
2. `/api/materials` 支持按 `retrievalTarget` 和 `query` 检索。
3. 图文生成时拆成“文案依据”和“配图素材”两个小检索。
4. 视频脚本生成时只把文本知识和爆款内容作为脚本依据，不提前绑定具体剪辑素材。
5. 创建 AI 剪辑任务时，worker payload 只接收视频资产，并保留分镜素材 query / 缺失画面提示。
6. 素材缺失时，不出现裸技术错误，用户能看到可继续操作的降级路径。

## 2. 测试范围

### 2.1 本轮必测

- 商家端登录后 `/dashboard` 可进入。
- 素材 / 知识库入口可访问。
- 图文工作台可访问。
- 视频工作台可访问。
- 素材相关 API 未登录时仍受认证保护。
- 登录态下核心页面不出现 500、白屏、无限加载。
- 可见文案符合“素材分层”语义：爆款内容用于表达参考，图片用于图文配图，视频用于 AI 剪辑。

### 2.2 本轮可选

受账号数据、素材数据和真实 LLM / COS 状态影响，以下项目如果当前账号缺少条件，可以记录为“环境不足，待数据准备后复测”：

- 真正生成图文并检查 `input_snapshot.materialRetrieval`。
- 真正确认脚本并创建 AI 剪辑任务。
- 在 Supabase 中检查最新 draft / job payload。

### 2.3 非目标

- 不测试真实账号发布。
- 不要求完成真实视频多模态识别、ASR/OCR、时间码切片。
- 不要求验证图片生成链路。
- 不要求验证 production 环境。

## 4. 点击测试用例

- [ ] 访问 `/dashboard`。
- [ ] 页面能正常加载商家端主导航。
- [ ] 页面不出现 500、404、空白页或登录态异常循环。

- 如果被重定向到登录页，需要记录为“登录态失效”，不算功能失败。

### TC-02 素材 / 知识库入口

- [ ] 从商家端进入素材或知识库页面。
- [ ] 页面存在文本资料 / 爆款内容 / 项目媒体素材相关入口或区域。
- [ ] 能看到项目图片素材和项目视频素材的用途区分。
- [ ] 视频素材若处于处理中，应显示“识别中 / 处理中 / 待索引”等非错误状态。
- [ ] 页面不出现把爆款内容描述成“可直接剪辑视频素材”的文案。

通过标准：

- 页面能表达至少三类素材：知识文本、爆款参考、项目媒体素材。
- 项目图片和项目视频的用途文案不混淆。

### TC-03 素材 API 分层查询

在浏览器登录态下或通过页面触发，验证以下 API 语义：

- [ ] `GET /api/materials?retrievalTarget=copy_context&query=刚需买房`
- [ ] `GET /api/materials?retrievalTarget=article_image_asset&query=样板间客厅`
- [ ] `GET /api/materials?retrievalTarget=video_edit_asset&query=项目外立面远景`

通过标准：

- 未登录时返回 `401 UNAUTHENTICATED`，说明路由受认证保护。
- 登录态下返回 JSON，且每条素材的 `retrievalTargets` 包含请求的 `retrievalTarget`。
- 不同 `retrievalTarget` 不应返回明显不属于当前用途的素材。

### TC-04 图文工作台：文案依据与配图素材拆分

- [ ] 进入图文工作台或从今日图文任务进入。
- [ ] 触发图文生成入口，或查看已有图文生成结果。
- [ ] 页面可见标题、正文、标签、CTA、封面字或配图建议。
- [ ] 若存在项目图片素材，配图建议只展示图片素材或图片用途建议。
- [ ] 若没有图片素材，页面应展示图片 brief / prompt / 可补充图片素材提示。
- [ ] 页面不应把视频素材当图文配图。

通过标准：

- 图文内容生成链路可用。
- 缺图时是降级提示，不是技术错误。

### TC-05 视频工作台：脚本画面需求

- [ ] 进入视频工作台或从今日视频任务进入。
- [ ] 触发视频脚本生成入口，或查看已有视频脚本。
- [ ] 脚本包含 hook、口播、字幕或分镜段落。
- [ ] 每个分镜尽量能看到画面要求、素材、拍摄提示或替代画面。
- [ ] 页面不声称爆款视频已经成为当前项目可剪辑素材。

通过标准：

- 视频脚本阶段输出“需要什么画面”，而不是直接绑定具体素材文件。

### TC-06 AI 剪辑任务：视频素材隔离与缺失提示

- [ ] 在视频工作台中确认脚本。
- [ ] 尝试创建 AI 剪辑任务。
- [ ] 若草稿没有视频素材，应提示缺少画面 / 需要上传视频 / 可补拍素材。
- [ ] 若草稿有视频素材，任务创建后不应把图片素材作为 worker 主输入。
- [ ] 若能看到任务状态，任务不应因为爆款内容或图片素材被错误当作视频输入而报错。

通过标准：

- 创建任务阶段只消费视频资产。
- 素材不足时给用户可理解提示。

## 7. 结论

V2.4 主链路点击验证通过：图文、视频脚本和 AI 剪辑任务都能按不同检索目标记录分层上下文；图文缺图片素材时已经有明确降级提示；AI 剪辑任务没有把错误素材类型传入 worker。

本轮唯一需要补强的是 TC-06 的用户可见提示：虽然 payload 已记录 `missingVideoAssetHints`，但页面未把“缺少可剪辑视频素材”的事实显式告诉用户，容易让用户误以为素材已经足够。

## 8. 风险与备注

1. 当前 V2.4 未新增 Supabase migration，素材检索排序先在服务端基于现有 `source_items` 候选重排。
2. 项目视频素材从 `parsing` 到 `ready` 仍依赖后续 asset analyzer / 多模态索引 worker。
3. 当前测试账号缺少项目图片 / 视频素材，因此非空素材命中、视频素材片段匹配、ASR/OCR 后索引结果仍需在准备测试素材后复测。
4. 直接用 shell `curl` 访问 staging alias 时出现 TLS / 代理异常，浏览器实际访问正常；本轮以浏览器登录态和 Vercel inspect 的 `Ready` 状态为准。
