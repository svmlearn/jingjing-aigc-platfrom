# 视频剪辑测试：输入脚本完整度案例脚本

创建时间：2026-05-15

对应飞书表格：`视频剪辑测试文档` / `案例对比总表（副本）`

本文件用于准备一组“控制变量法”测试样例。测试目标是验证：在素材、口播方式、目标时长、画幅都固定的情况下，`输入-镜头脚本` 的完整度变化会如何影响视频生成结果。

## 统一控制变量

| 字段 | 固定内容 |
|---|---|
| 输入-主题 | 藏在楼群里的小院咖啡，适合慢下来坐一会儿 |
| 输入-用户上传素材 | 同一组门店视频素材 + 真人开头口播素材 + 真人结尾口播素材 + 克隆口播参考音频 |
| 输入-口播方式 | 真人口播 + 中段口播 |
| 输入-目标时长 | 45秒 |
| 输入-画幅 | 9:16 |
| 台词/字幕规则 | `台词/字幕` 是同一个字段，既代表口播实际说的话，也代表屏幕字幕内容 |
| 花字规则 | 卖点短句单独写为“画面花字”，不要和 `台词/字幕` 混在一起 |

## 素材命名建议

为保证不同案例之间只改变脚本完整度，建议素材命名和使用范围固定如下：

| 素材编号 | 素材名称 | 用途 |
|---|---|---|
| 素材01 | 外立面/招牌/入口素材 | 开场环境、门店识别 |
| 素材02 | 入口动线素材 | 从外部走进店里的过程 |
| 素材03 | 庭院/草坪/桌椅素材 | 主体空间展示 |
| 素材04 | 饮品/桌面细节素材 | 消费动作和停留感 |
| 素材05 | 真人开头口播.mp4 | 片头真人出镜 |
| 素材06 | 真人结尾口播.mp4 | 片尾真人出镜 |
| 素材07 | 克隆口播参考音频.m4a | 中段口播或声音克隆参考 |

### 表格字段建议

| 输入-镜头脚本 | 使用下方完整脚本 |

| 输入-目标时长 | 45秒 |
| 输入-画幅 | 9:16 |

### 输入-镜头脚本

```text
1
00:00-00:05
场景：真人开头口播
画面：真人面对镜头，背景在门店入口或庭院，画面稳定，人物看向镜头。
台词/字幕：如果你想找一个不吵、能坐一会儿的咖啡小院，可以看看这家。
画面花字：楼群里的小院咖啡
素材：素材05 真人开头口播.mp4

2
00:05-00:12
场景：入口动线
画面：从外立面、招牌或入口通道切入，展示从街区走进门店的过程。
台词/字幕：它不是商场里一眼看完的店，更像是走进去以后才发现的安静角落。
画面花字：走进去，才发现里面很安静
素材：素材01 外立面/招牌/入口素材；素材02 入口动线素材

3
00:12-00:24
场景：庭院空间
画面：展示草坪、白色桌椅、空座位和庭院整体空间，镜头节奏放慢。
台词/字幕：进来之后，先看到的是这片小草坪和几组座位，人不多的时候，很适合慢慢坐一会儿。
画面花字：小草坪 + 户外座位
素材：素材03 庭院/草坪/桌椅素材

4
00:24-00:34
场景：饮品和桌面细节
画面：展示杯子、桌面、手部动作、玻璃反光或室内近景，承接“坐下来”的动作。
台词/字幕：点一杯喝的，手机放旁边，节奏就会自然慢下来。
画面花字：点一杯，坐下来
素材：素材04 饮品/桌面细节素材

5
00:34-00:45
场景：真人结尾口播
画面：真人面对镜头，背景在庭院或门店入口，最后一秒画面停稳。
台词/字幕：想知道具体位置和营业时间，可以先收藏，或者私信问我。
画面花字：先收藏｜私信问定位和营业时间
素材：素材06 真人结尾口播.mp4
```

## CASE-005 小院咖啡-简略脚本版

### 表格字段建议

| 字段 | 内容 |
|---|---|
| 案例编号 | CASE-005 |
| 案例名称 | 小院咖啡-简略脚本版 |
| 输入-主题 | 藏在楼群里的小院咖啡，适合慢下来坐一会儿 |
| 输入-镜头脚本 | 使用下方脚本 |
| 输入-用户上传素材 | 素材01-素材07 |
| 输入-口播方式 | 真人口播 + 中段口播 |
| 输入-目标时长 | 45秒 |
| 输入-画幅 | 9:16 |
| 备注 | 只给段落顺序和核心要求，不给逐段时间、台词/字幕和素材指定 |

### 输入-镜头脚本

```text
本条视频做成 45 秒左右，9:16 竖版。

结构要求：
1. 开头必须是真人出镜口播，真人面对镜头介绍这家藏在楼群里的小院咖啡。
2. 中段展示门店入口，让用户知道这家店是从外面走进去才看到的。
3. 中段展示庭院空间，重点突出草坪、桌椅、安静、不吵、不挤。
4. 中段展示饮品和桌面细节，表达“点一杯、坐下来、慢一点”的感觉。
5. 结尾必须是真人出镜口播，引导用户收藏或私信询问定位和营业时间。

台词/字幕要求：
台词/字幕是同一个字段，既作为实际口播，也作为屏幕字幕。

画面花字可以使用：
楼群里的小院咖啡
走进去，才发现里面很安静
小草坪 + 户外座位
点一杯，坐下来
先收藏｜私信问定位和营业时间
```

## 跑测后建议填写的观察项

建议在 `问题记录` 或详情页中记录以下内容：

| 观察项 | 记录方式 |
|---|---|
| 首尾真人口播是否保留 | 是 / 否；如否，记录缺失位置 |
| 台词/字幕是否和实际口播一致 | 是 / 否；记录错字、漏字、提前出现或集中出现 |
| 花字是否误当台词/字幕 | 是 / 否 |
| 素材是否匹配脚本段落 | 1-5 分 |
| 剪辑是否突兀 | 1-5 分 |
| 口播前后声音是否一致 | 1-5 分 |
| 输出成片是否可用 | 可用 / 需轻改 / 需重做 |
| 主要失败原因 | 脚本缺字段 / 素材选择错 / 台词字幕错位 / 口播不自然 / 其他 |
