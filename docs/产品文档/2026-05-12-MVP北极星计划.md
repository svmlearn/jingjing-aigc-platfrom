# 2026-05-12 MVP 北极星计划

## 目标

MVP 的核心目标是跑通一条可验证的内容生产链路：

用户与 AI 交互生成一周内容营销日历，基于内容日历、爆款内容、TXT 知识库和图片素材生成图文内容包与视频镜头脚本，再把镜头脚本和视频素材交给 worker 生成可用成片。

## 当前总进度

### 第一部分：AI 交互生成一周内容营销日历

负责人：我

状态：已完成

目标：与 AI 交互后，能生成一周的内容营销日历。

### 第二部分：内容日历到图文内容包 / 视频镜头脚本

负责人：我

目标：提升这条链路的质量与稳定性。

输入：

- 内容日历
- 爆款内容
- TXT 知识库
- 图片素材

输出：

- 图文内容包
- 视频镜头脚本

实施步骤：

1. 用 Dify 实现 flow 流程，方便调试。当前 demo 已有。
2. 将 Dify 接入到代码中，测试整体连通性。
3. 将 Dify 换成 LangGraph 实现，并进行测试。

当前关注点：

- Dify V3.0 已完成图文与视频节点拆分。
- 中间 LLM 节点不强依赖 nested `structured_output.xxx` 子变量，优先传整包 `text` JSON。
- Code 节点与最终输出继续保持严格 JSON，保证后续 API 接入和前端消费稳定。
- 后续接入代码时，需要验证 API 调用、任务输入、最终 JSON 落库、图文/视频工作台展示是否连通。

### 第三部分：镜头脚本到 AI 剪辑成片

负责人：孟金昊

目标：验证 worker 部分能把视频镜头脚本和素材转成 MVP 可用成片。

输入：

- 镜头脚本
- 用户上传视频素材
- 团队视频素材

MVP 质量目标：

- 有背景音乐
- 能把用户上传视频素材和团队视频素材拼接起来
- 转场不突兀
- 字幕能对上时间线
- 口播能念字幕

MVP 实施步骤：

1. 可以在本地实现 AI 剪辑成片。当前已完成。
2. 在云端代码环境中跑通该流程。
3. 搭建 COS 素材库，包括素材打标签和 API 替换。
4. 接入声音克隆，或先使用默认稳定音色，保证口播音色一致。

后续优化点：

1. AI 找到更加合适的视频素材：优化素材语义识别，能合理识别各素材、切片并组合。
2. Agent 剪辑更加符合传入的镜头脚本，而不是自由发挥。
3. 用 Suno 或其他方式生成一批可商用背景音乐素材，规避版权风险。

## 近期优先级

1. 先确认 Dify V3.0 三个核心测试用例稳定通过或按预期降级。
2. 明天优先接入 Dify API，跑通“内容日历 -> 图文内容包 / 视频镜头脚本 -> 代码链路”的整体连通性。
3. 再决定 LangGraph 迁移的节点边界：保留最终 JSON 契约，逐步替换 Dify 编排。
4. worker 侧并行推进云端跑通、COS 素材库和字幕/口播时间线稳定性。

## 验收口径

MVP 不追求一次性做到最智能，优先追求链路可跑、结果可看、问题可定位。

最低验收标准：

- 一周内容营销日历可以生成。
- 每条日历任务能生成图文内容包和视频镜头脚本。
- 输出 JSON 可解析，关键字段稳定。
- 风险表达不进入公开成稿。
- 缺素材、弱知识库等场景能降级提示，而不是编造。
- 视频 worker 能基于镜头脚本生成一条可预览成片。
- 整条链路的失败点能通过日志、节点输出或任务状态定位。
