# V0.1-A 实现任务拆解

## 1. 当前实现目标

`V0.1-A` 只追一条主链路：

```text
邀请码注册
-> 商户资料
-> Apify 导入
-> 内容中心
-> AI 改写
-> 保存草稿
```

暂不实现：

- 自动发布
- 发布账号管理
- 多成员协作
- 店铺/门店层
- BI 看板
- 定时监控博主

---

## 2. 阶段一：项目底座

### 2.1 前端/后端一体项目

推荐：

- `Next.js`
- `Vercel`
- `Supabase`

需要创建：

- 页面路由
- 服务端 API routes / server actions
- Supabase client
- 环境变量管理

### 2.2 环境变量

```bash
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
APIFY_TOKEN=
OPENAI_API_KEY=
```

注意：

- `APIFY_TOKEN` 只能在服务端使用
- `SUPABASE_SERVICE_ROLE_KEY` 只能在服务端使用

### 3.2 RLS 策略

`V0.1-A` 有两种选择：

1. 后台所有写操作走服务端 `service_role`
2. 开启 RLS，按 `owner_user_id / merchant_id` 做隔离

推荐默认：

- 页面读写尽量走服务端
- RLS 策略可以在 app scaffold 后补

## 4. 阶段三：邀请码注册

### 4.1 页面

```text
/register
/merchant/onboarding
```

### 4.2 API

```text
POST /api/auth/register-with-invite
POST /api/invitation-codes
```

### 4.3 逻辑

注册时：

1. 校验邀请码
2. 创建 Supabase auth user
3. 创建 `merchant_profiles`
4. 回填 `invitation_codes`
5. 登录并进入商户资料页

## 5. 阶段四：Apify 导入

### 5.1 核心模块

参考：

- [V0.1-ApifyProviderAdapter-接口设计草案.md](/Users/wy/Desktop/静境/静境4.0/小红书抖音矩阵获客平台/docs/架构规范/V0.1-ApifyProviderAdapter-接口设计草案.md)

```text
  adapter.ts
  actors.ts
  normalize-xiaohongshu.ts
  normalize-douyin.ts
  errors.ts
```

### 5.2 API

```text
POST /api/import-jobs
GET  /api/import-jobs
GET  /api/import-jobs/:id
POST /api/import-jobs/:id/run
POST /api/import-jobs/:id/retry-comments
```

### 5.3 必须实现的保护

- 同一商户同时最多一个 running 任务
- 评论默认最多 `30` 条
- run 成功后做结果质量校验
- 空 dataset 不直接算成功
- 正文成功但评论失败时标记 `partial`

### 7.1 页面

```text

```

### 7.2 API


### 7.3 输入上下文

AI 改写至少需要：

- 来源标题
- 来源正文
- 评论摘要
- 商户名称
- 地址
- 联系人
- 联系电话
- 服务项目
- 目标平台
- 改写方向

## 8. 阶段七：验收清单

### 8.1 导入验收

- 小红书帖子链接能导入正文
- 小红书帖子链接能导入评论
- 小红书博主主页能导入帖子列表
- 抖音视频链接能导入详情
- 抖音视频链接能导入评论
- 无效链接能返回清晰错误
- 低质量结果不会直接进入改写

### 8.2 改写验收

- 能基于来源内容生成小红书版本
- 能基于来源内容生成抖音口播版本
- 能引用商户服务项目
- 能保存多个版本
- 能继续编辑草稿

---

## 9. 当前建议的开发顺序

1. 初始化 Next.js + Supabase 项目
2. 接入 Supabase migration
3. 做邀请码注册
4. 做商户资料页
5. 做 ApifyProviderAdapter
6. 做导入页
7. 做内容中心
8. 做改写工作台
9. 做草稿保存

---

## 10. 下一步需要用户确认

如果从文档进入真实开发，建议先确认：

1. 项目代码放在当前目录下，还是新建一个 `app` 子目录
2. 前端是否默认采用 `Next.js + Tailwind + shadcn/ui`
3. Supabase 项目是否已经创建
4. 是否现在就把 Apify token 写入本地 `.env.local`

在确认前，不建议直接初始化工程，以免污染当前资料目录。
