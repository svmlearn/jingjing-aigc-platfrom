# V2.4 声音克隆未来计划

日期：2026-05-13

## 文档定位

本文档只记录未来功能方案，不进入当前实现范围。

本阶段不改业务代码、不建表、不新增接口、不接入真实 TTS 克隆链路。后续如果启动开发，可将本文档拆成 PRD、技术设计和开发任务。

## 背景

当前用户端视频工作台已有脚本生成、脚本确认、素材上传和 AI 一键剪辑链路，也已有普通 TTS/配音 provider 配置。但用户端还没有声音克隆入口，无法录制或上传声音样本，也无法在视频生成时指定克隆音色。

未来需要在 AI 剪辑前增加一个明确的声音克隆选择步骤，让用户可以把自己的声音保存为可复用音色，并在视频成片 TTS 阶段使用该克隆音色。

## 目标体验

用户端 AI 剪辑页未来增加“声音克隆”专属框，位置放在脚本/镜头内容下方、AI 一键剪辑上方，视觉风格与周围视频工作台保持统一。

用户可在该框内完成：

- 选择“使用系统配音”或“使用我的克隆音色”。
- 录制一段声音，或上传音频文件作为兜底。
- 保存为个人私有可复用音色。
- 保存前必须勾选声音授权确认。
- 在 AI 一键剪辑前选择一个已保存的克隆音色。

选择克隆音色后，视频任务的 TTS 应使用该克隆音色，不再走普通系统配音。

## 产品决策

- 音色生命周期：做成个人私有、可复用音色。
- 可见范围：仅创建者本人可见、可使用；不做商户团队共享。
- 输入方式：优先浏览器录音，同时支持上传音频作为权限失败或已有素材的兜底。
- 合规要求：保存音色前必须强制勾选授权确认。
- 失败策略：克隆失败时明确报错并允许重试，不静默降级为普通配音。
- UI 位置：放在脚本内容下方、AI 一键剪辑操作上方，作为正式剪辑前的配置步骤。

## 技术方案

声音克隆参考 `pixell-video` 的 RunningHub Index-TTS 方案。

后端不单独部署 `pixell-video` 服务，而是把最小声音克隆 TTS 能力并入现有 `video-worker/OpenStoryline` 链路。

规划中的数据与接口改动：

- 新增个人音色表 `voice_profiles`，记录音色名称、归属用户、参考音频、状态和授权确认时间。
- 媒体资产类型增加 `audio`，用于保存录音或上传的参考音频。
- 新增 `/api/voice-profiles` 相关接口，用于创建、列表、重命名和停用个人音色。
- 视频任务 `productionConfig.voiceover` 增加：
  - `mode: "default" | "cloned"`
  - `voiceProfileId?: string | null`
- 当 `mode="cloned"` 时，服务端校验 `voiceProfileId` 属于当前用户，并把参考音频写入 worker payload。
- worker 下载参考音频后，将本地路径传给 OpenStoryline TTS 配置。
- OpenStoryline 在克隆模式下调用 RunningHub Index-TTS 工作流生成旁白音频。

## 验收方向

- 默认不影响现有 TTS 链路。
- 未选择声音克隆时，普通 AI 剪辑行为保持不变。
- 克隆模式必须选择已保存音色，否则不能创建 AI 剪辑任务。
- 非本人音色不能被查看或用于视频任务。
- 保存音色前必须完成授权确认。
- 克隆失败要在任务状态中明确暴露，并允许用户重试。
- 克隆失败不静默降级普通配音。

## 后续拆解

1. PRD 补充
   - 明确录音时长、文件大小、支持格式和授权文案。
   - 明确音色列表、重命名、停用和重录体验。

2. 数据层
   - 增加 `voice_profiles` 迁移。
   - 扩展 `asset_objects.asset_type` 允许 `audio`。
   - 补充 RLS/服务端权限校验，保证个人私有。

3. API 层
   - 新增音色创建、列表、重命名、停用接口。
   - 扩展媒体上传接口允许音频。
   - 扩展视频任务创建 schema 和 payload 构建逻辑。

4. 前端
   - 在视频工作台新增声音克隆专属框。
   - 接入 `MediaRecorder` 录音、上传音频、试听、保存音色和选择音色。
   - 在克隆模式下阻止未选择音色的 AI 剪辑提交。

5. Worker 与 TTS
   - 扩展 worker 下载参考音频。
   - 接入 RunningHub Index-TTS 克隆工作流。
   - 补充失败状态、日志脱敏和重试策略。

## 非目标

- 当前不做团队共享音色。
- 当前不做音色市场。
- 当前不做独立 `pixell-video` 服务部署。
- 当前不做在线试听生成效果。
- 当前不改变普通系统配音的默认行为。
