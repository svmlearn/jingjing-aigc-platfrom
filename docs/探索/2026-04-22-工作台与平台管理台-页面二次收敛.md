# 2026-04-22 工作台与平台管理台页面二次收敛

这份文档用于记录 2026-04-22 对 Pencil 二版设计稿的页面边界修正，避免后续把设计稿中的动作语义和底层实现状态混淆。

## 1. 商家工作台

### 1.1 内容中心

内容中心里的来源内容卡片，动作拆成三个：

- `预览`：留在内容中心内，打开右侧详情抽屉快速查看
- `详情`：进入独立内容详情页
- `改写`：直接进入改写工作台

这样做的原因：

- 桌面端仍可保留高频快速浏览
- 页面级详情不再和抽屉语义混用
- 改写入口保持最短路径

### 1.2 内容详情页

内容详情页作为独立页面存在，承接：

- 来源正文
- 评论洞察
- 评论列表
- 进入改写

它不是抽屉的“放大版”，而是用户决定是否进入改写前的完整判断页。

## 2. 平台管理台

### 2.1 总览

总览页拆成三类信息，不再混写：

1. `业务摘要`
   - 今日导入
   - 今日改写
   - 失败任务
   - 活跃商户

2. `管理员操作日志`
   - 生成邀请码
   - 禁用商户
   - 更新模型配置
   - 轮换 API Key

3. `系统告警`
   - OpenAI 失败率升高
   - Apify 超时
   - 商户积分耗尽

### 2.2 邀请码管理

邀请码管理页负责列表、筛选和状态查看。

新增一个明确的 `新建邀请码` 流程，建议用右侧面板或独立页面承接，字段包括：

- 自动生成 / 手动填写
- 用途：`merchant_signup`
- 最大兑换次数
- 过期时间
- 备注 / 渠道标签

### 2.3 商户管理

商户管理页至少展示：

- 商户名
- owner
- 状态
- 会员等级
- 今日剩余积分
- 最近活跃时间

并新增 `商户详情` 页面，承接：

- 商户基础信息
- 状态切换：启用 / 禁用 / 归档
- 会员等级：`free / plus / pro`
- 积分规则摘要
- 最近任务概况

### 2.4 系统配置

系统配置页不再只展示“默认改写模型”，而是升级为 `LLM Provider 配置 + 会员积分规则`。

`LLM Provider 配置` 至少包含：

- Provider 名称
- Base URL
- API Key（掩码）
- 默认主模型
- 备用模型
- temperature
- max tokens
- timeout
- 重试次数

`会员与积分规则` 先按三档预设：

- `free`：20 点/天
- `plus`：100 点/天
- `pro`：300 点/天

先按 `1 次改写 = 1 点` 理解，后续允许调整。

## 3. 对数据层的提醒

这轮只是页面与信息架构收敛，不代表底层已经完整实现。

当前已知仍需后续补齐的底层能力：

- `merchant_profiles.status` 目前仍只有 `active / archived`，后续如要支持“禁用商户”，需补 `disabled`
- 平台级 LLM / Apify 配置目前仍主要依赖环境变量，后续如要在线管理，需要补配置表与安全存储方案
- 会员等级与积分规则当前尚未正式入库，需要在数据模型里单独落位
