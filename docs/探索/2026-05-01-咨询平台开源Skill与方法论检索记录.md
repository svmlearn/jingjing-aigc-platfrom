## 1. 本次想检索什么

本次检索目标不是找泛泛的 AI 营销工具，而是找更接近本项目“咨询台”要做的开源参考：

- 个人 IP 咨询：帮助用户挖掘定位、亮点、优势、表达风格、内容主张。
- 企业 / 产品咨询：帮助商家挖掘产品卖点、目标客群、差异化、价值主张、成交话术。
- 可沉淀形态：优先找 prompt、agent skill、咨询流程、结构化输出模板，而不是单次文案生成器。
- 项目价值：最好能被拆成我们自己的咨询台问题流、方法论卡片、Skill、RAG 资料或阶段性工作流。

默认筛选条件：

- GitHub 公开仓库。
- `stars >= 100`。
- `archived=false`。
- 相关性优先，不按 star 机械排序。

## 4. 对“这些是不是 Skill”的判断

这次最关键的发现是：很多有价值的参考已经不是传统代码项目，而是 Skill / Skill pack / workflow pack。

分类如下：

- `ai-marketing-claude-code-skills`：是 Skill pack。
- `StartupKit`：是 Skill + 多阶段 workflow / session orchestrator。
- `osp_marketing_tools`：不是传统 Skill，但它是 MCP server + 方法论 prompt，可转成我们自己的 Skill。
- `phuryn/pm-skills`：是大型 PM Skill marketplace。
- `fullstack-mkt-skills`：是营销 Skill pack。

因此，本项目后续如果要支持 Skill，这批参考非常合适。

## 5. 对本项目咨询台的吸收建议

### 5.1 第一阶段：先做自己的咨询 Skill 骨架

建议先拆成 3 个内部 Skill：

1. `consulting-positioning-personal-ip`
   - 面向个人 IP。
   - 参考 `ai-marketing-claude-code-skills/positioning-basics`。
   - 输出：人设定位、优势标签、差异化、内容支柱、简介文案。

2. `consulting-product-value-map`
   - 面向企业和产品。
   - 参考 `osp_marketing_tools/product-value-map-llm.md`。
   - 输出：产品定位、目标客群、核心卖点、价值案例、功能-利益映射。

3. `consulting-session-orchestrator`
   - 面向咨询流程编排。
   - 参考 `StartupKit/skills/startupkit/SKILL.md`。
   - 输出：阶段进度、已收集信息、缺失信息、下一步建议、最终咨询交付物。

### 5.2 第二阶段：把咨询结果接到内容生产

咨询台不是终点，它应该把结构化结果喂给后面的内容链路：

- 内容日历：根据定位、目标客群、内容支柱生成选题池。
- 图文工作台：根据卖点、案例、用户痛点生成小红书图文。
- 视频工作台：根据定位、场景、冲突、转化目标生成短视频脚本。
- 发布/复盘：根据内容表现反哺定位和卖点。

### 5.3 第三阶段：沉淀项目自己的 Skill 运行机制

既然外部参考越来越多是 Skill 形态，本项目可以考虑把咨询能力也拆成可版本化资产：

- Skill 文件：描述触发条件、上下文收集、输出格式、校验标准。
- Method references：放方法论、问题库、模板。
- Session state：记录咨询阶段、用户已确认内容、未确认假设。
- Output contracts：定义给内容日历 / 图文 / 视频工作台的结构化输出。
